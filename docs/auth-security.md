# Authentication security gate
Password authentication and TOTP enrollment/challenge UI use Supabase Auth. Tokens are held in memory only; page reload requires sign-in. Inactivity logout is a client-side mitigation, not a server-side expiry guarantee. The staged migration 003 requires aal2 on all nine public RPCs; do not apply before testing enrollment, login, verified MFA and lost-device recovery in preview. Email activation, paid entitlement, server-side session revocation check, HttpOnly BFF cookies, rate-limit/CAPTCHA settings and phishing-resistant passkeys remain required. No browser can guarantee protection against malware, screenshots, live screen mirroring or phishing proxies. The login background references src/login-hero.webp; add the approved image asset before visual acceptance.
